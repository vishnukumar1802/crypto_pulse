# Crypto Pulse PWA 🚀

A production-ready Crypto Tracker w/ Dark Neon Aesthetic.

## Features
- **Real-time Dashboard**: Live prices via CoinGecko Free API
- **Trend Predictor**: algorithmic signals based on OHLC
- **Portfolio & Watchlist**: Local storage + Firebase Auth
- **PWA**: Installable on mobile, offline support

## Setup
1. `npm install`
2. Create `.env` with Firebase Config (Already done)
3. `npm run dev`

## Tech Stack
- React 18 + Vite
- Tailwind CSS (Glassmorphism)
- Firebase Auth
- Dexie (IndexedDB)
- Chart.js
- Framer Motion
